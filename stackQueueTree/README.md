# stackQueueTree

This folder holds exercises and notes for stacks, queues, and tree data structures.

## What you'll find

- Explanations and small coding exercises for stack/queue implementations.
- Starter code and examples for basic tree traversal tasks.

## Examples

The repository includes simple stack and queue examples at the project root:

```bash
node StackLinkedList.js
node QueueLinkedList.js
```

Or run all examples from the root with:

```bash
node run_examples.js
```
