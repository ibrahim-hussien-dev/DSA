# Linked List Exercises

This folder contains simple JavaScript implementations of linked lists.

## Files

- [sll.js](sll.js) - Singly linked list implementation with methods like `push`, `pop`, `shift`, `unshift`, `get`, `set`, `insert`, `delete`, `search`, and `print`.
- [dll.js](dll.js) - Doubly linked list implementation with similar operations and support for both `next` and `prev` pointers.
- [index.js](index.js) - Small JavaScript practice file included in the folder.

## What is included

The linked list examples demonstrate how to:

- create nodes
- add and remove values
- search for a value
- update a node by index
- insert nodes at specific positions
- traverse the list from head to tail

## Running the examples

Make sure Node.js is installed, then run a file from this folder:

```bash
node sll.js
node dll.js
```

Each script includes sample usage and console output.
