# Sorting and Searching Algorithms

This folder contains simple JavaScript implementations of common sorting and searching algorithms.

## Files

- [linearSearch.js](linearSearch.js) - Linear search in an array.
- [binarySearch.js](binarySearch.js) - Binary search in a sorted array.
- [bubbleSort.js](bubbleSort.js) - Bubble sort implementation.
- [selectionSort.js](selectionSort.js) - Selection sort implementation.
- [insertionSort.js](insertionSort.js) - Insertion sort implementation.

## Running examples

Make sure Node.js is installed, then run any file from the repository root:

```bash
node Sort&search/linearSearch.js
node Sort&search/binarySearch.js
node Sort&search/bubbleSort.js
```

To run all curated examples across the repository:

```bash
node run_examples.js
```
