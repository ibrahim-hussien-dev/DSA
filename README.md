# JavaScript Algorithm Exercises

Collection of small JavaScript algorithm problems and solutions.

## Files

- [problem1_same.js](problem1_same.js) — Check if all values are the same.
- [problem2_validAnagram.js](problem2_validAnagram.js) — Determine if two strings are anagrams.
- [problem3_sumZero.js](problem3_sumZero.js) — Find a pair of numbers that sum to zero.
- [problem4_countUniqueValues.js](problem4_countUniqueValues.js) — Count unique values in a sorted array.
- [problem5_maxSubarraySum.js](problem5_maxSubarraySum.js) — Maximum subarray sum for a fixed-length window.
- [problem6_minSubArrayLen.js](problem6_minSubArrayLen.js) — Smallest subarray length with sum ≥ target.
- [problem7_findLongestSubstring.js](problem7_findLongestSubstring.js) — Length of longest substring without repeating characters.

## Usage

Ensure you have Node.js installed, then run any file with:

```bash
node problem7_findLongestSubstring.js
```

Replace the filename to run other problems.
